## Promotional Text

## Full Description
Dive into the multiverse with **MultiverseWiki**, a native SwiftUI iOS companion designed for fast browsing and reliable offline access.

**Key Capabilities**
- **Infinite Character Directory:** Smoothly paginate through characters from the Rick and Morty API with live connectivity handling and one-tap retry.
- **Deterministic Secret Dossiers:** Unlock unique, consistent dossier entries generated from each character's origin, species, status, and galactic archive ID.
- **Offline-Ready Favorites:** Bookmark characters into on-device Core Data storage, read saved dossiers without internet access, and edit or organize your saved entries anytime.
- **Account Support:** Secure email and password authentication powered by Firebase Auth.

## Privacy Summary
- **Authentication Data:** User email addresses and credentials are processed strictly for sign-in and account creation via Firebase Authentication.
- **Local Storage:** Favorited characters, edits, and saved dossiers are stored locally on the user's device using Apple Core Data.
- **Tracking:** No third-party ad tracking or cross-app behavioral analytics are enabled.
